# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリはGithubなどクラウド上に保存されており、ローカルリポジトリは自分のパソコン内に保存されている


## プッシュとマージの違いは何でしょうか？
- プッシュは変更内容をリモートリポジトリに保存することで、マージはブランチの保存内容をメインに保存すること


## コミットとプッシュの違い
- コミットはメッセージをつけて変更を保存することで、プッシュはリモートリポジトリに保存すること


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 変更点を簡潔にわかりやすく書く


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- ローカルでマージするとメインが完成した状態でリモートリポジトリに保存され、プルリクエストの場合はマージ前に他の人がコードを読んでコメントしたり修正を頼んだりできる。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- どちらか片方を残すか、両方残すか、まったく新しく書き直すかを決める
